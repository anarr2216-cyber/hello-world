# 🚗 汽機車獨立專屬保養管理 PWA 系統 (支援車輛增刪改查 & 雲端同步)

本專案支援將保養管理介面直接「加入手機主畫面（PWA App）」，支援**自由新增、修改、刪除車輛**，並透過 Google Apps Script 實現所有裝置輸入自動同步寫入 Google Drive 試算表！

---

## 🚗 一、車輛管理功能操作說明

1. **新增車輛**：
   - 點擊頂部車輛橫條右側的 **「新增車輛」** 或底部 **「車庫管理」** 進入新增彈窗。
   - 輸入車輛代號 (如: `Car-03`, `Moto-02`)、車牌、車型、年份、初始總里程與選擇代表圖示即可。
2. **修改車輛**：
   - 選擇要修改的車輛後，在主卡片右上角點擊 **「✏️ (修改)」按鈕**，即可編輯車牌、型號、里程或圖示。
3. **刪除車輛**：
   - 點擊卡片右上角的 **「🗑️ (刪除)」按鈕**，系統確認後即可將車輛從車庫中安全移除。

---

## 📱 二、如何將網頁加入手機主畫面（安裝為 App）

### 🍏 iPhone / iPad (iOS Safari)
1. 使用 **Safari 瀏覽器** 開啟本網頁 (`index.html`)。
2. 點擊瀏覽器底部的 **「分享按鈕」**（向上箭頭的方框圖示）。
3. 向下滾動選單，點選 **「加入主畫面 (Add to Home Screen)」**。
4. 點擊右上角「新增」，桌面即會出現獨立的 **「車輛保養」App 圖示**！

### 🤖 Android 手機 (Chrome)
1. 使用 **Google Chrome 瀏覽器** 開啟本網頁。
2. 點擊右上角的 **「⋮」選單按鈕**。
3. 點選 **「安裝應用程式」** 或 **「加到主畫面」** 即可。

---

## ☁️ 三、如何串接 Google Drive 雲端自動同步（Google Sheets）

1. 打開 [Google 雲端硬碟](https://drive.google.com/)，建立一個新的 **Google 試算表**。
2. 點選上方選單 **「擴充功能」->「Apps Script」**。
3. 清空編輯器中的代碼，將專案中的 `google-apps-script.js` 內容貼上。
4. 點選右上角 **「部署」->「新部署」**：
   - 種類選擇：**「網頁應用程式 (Web App)」**
   - 執行身分：**我 (您的 Google 帳號)**
   - 誰可以存取：**任何人 (Anyone)**
5. 點選「部署」並複製產生的 **網頁應用程式網址 (Web App URL)**。
6. 打開手機 PWA 網頁，點擊右上方 **「雲端同步」**，將網址貼入並儲存。
7. 車輛清單、保養與加油紀錄均會即時雙向同步！
