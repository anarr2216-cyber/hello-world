# 🚗 汽機車獨立專屬保養管理 PWA (跨裝置全自動雙向同步版)

## ❓ 為什麼之前放在 GitHub Pages 上手機與電腦沒有同步？

1. **GitHub Pages 只是靜態檔案託管**：它本身沒有資料庫，無法幫您在伺服器端儲存跨裝置的資料。
2. **預設儲存在個別裝置的瀏覽器 (LocalStorage)**：在電腦瀏覽器新增的資料只存在電腦硬碟，手機瀏覽器只存在手機中，兩者互不相通。
3. **缺少「開啟自動讀取雲端 (doGet)」的機制**。

---

## 🌟 解決方案：3 步實現手機與電腦 100% 即時雙向同步！

### 第一步：在 Google Drive 部署後端 API (只要做一次)
1. 打開 [Google 雲端硬碟](https://drive.google.com/)，建立一個新的 **Google 試算表**。
2. 點擊頂部選單 **「擴充功能」>「Apps Script」**。
3. 清空代碼編輯器，將本專案內的 `google-apps-script.js` 完整複製貼上。
4. 點擊右上角 **「部署」>「新部署」**：
   - 種類選擇：**「網頁應用程式 (Web App)」**
   - 執行身分：**我 (您的 Google 帳號)**
   - 誰可以存取：**任何人 (Anyone)** *(重要：這樣手機與電腦才能傳輸)*
5. 點擊「部署」，複製產生的 **網頁應用程式網址 (Web App URL)**。

### 第二步：在「電腦網頁」貼上網址
- 開啟 GitHub Pages 網頁，點擊右上角 **「雲端同步」**，貼上剛才複製的網址並儲存。

### 第三步：在「手機 App / 網頁」也貼上同一個網址
- 手機開啟同一個 GitHub Pages 網頁，點擊右上角 **「雲端同步」**，貼上同一個網址並儲存。

🎉 **大功告成！**
現在只要在電腦新增車輛或保養紀錄，手機打開或按右上角「🔄 (重新整理)」按鈕，就會**自動從 Google 試算表拉取最新數據**；在手機輸入的紀錄也會**秒級同步寫入 Google Drive**！
